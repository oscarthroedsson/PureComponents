The class goes on the <ul>. Every clickable cell is a .pu-btn, so the row has no hover, focus or disabled rules of its own — it borrows the button's. Only the ellipsis is this file's.

Class names

Class Type Description
pagination Component The row. Goes on the <ul>.
pagination-ellipsis Part The gap marker between two page numbers.
btn Required Every clickable cell. From button.css, on an <a> or a <button>.
sm Size On the <ul>, not on the buttons.
md Size Default.
lg Size
sharp Shape Square corners.
smooth Shape Default corner, whatever the size gives.
rounded Shape Pill.

Sizes

Class Font size Gap Radius Cell

State

Attribute Goes on Description
aria-current="page" the current cell The page being viewed. Carries the meaning; the fill only follows it.
aria-disabled="true" an <a> Previous or next at either end. A link can never match :disabled.
disabled a <button> The same end state, where the control is script-driven.
aria-hidden="true" the ellipsis, the arrows Decoration. The link itself takes an aria-label.

Variables

Variable Default What it moves
--pagination-gap var(--spacing-25) Space between the cells.
--pagination-font-size var(--font-size-md) Inherited by the buttons, which declare no size of their own.
--pagination-cell-size 2.25em How narrow a cell may get. In em, so it tracks the type.
--pagination-radius var(--radius-md) The corner of every cell. The shape classes replace it.
--pagination-muted-color var(--color-neutral-500) The ellipsis.

The current page is a plain .pu-btn, the rest are .pu-btn ghost — the difference is made of the button's own variants, not of colours this file invents.

The ellipsis stands between two real page numbers, so it is decoration and takes aria-hidden="true". It is the only part of the row that is not a button.

A page with a URL is a destination, so it is an <a>. A page the script swaps in place is an action, so it is a <button>. The same class gives the same box either way — the button inherits its type from the row instead of falling back to the system font.

The size sits on the <ul> and reaches the buttons from there — they carry no size class of their own. Cell width is in em, so it follows along.

sharp, smooth and rounded replace the radius the size gives.

Every state is an attribute, never a class. Hover, focus and active are the button's and need no markup at all — point at a cell or tab into one in the result pane to see them. aria-current and the disabled ends are below.

Set the variables anywhere above the row — inline here so each change stands next to its result. Nothing below needs a new class.
