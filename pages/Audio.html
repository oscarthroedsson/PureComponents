Audio keeps the browser's own controls. PureUI gives the player a predictable outer size and shape, then adds a small Chromium-only paint layer through private media pseudo-elements. Firefox and other engines keep their native controls instead of receiving a broken imitation.

The native controls are the component. The CSS never removes a button, replaces an icon or reconstructs seeking and volume. That line is what lets the component stay CSS-only.

Class names

Class Type Description
audio Component Goes on the native <audio> element.
sm Size Tighter spacing between controls in Chromium.
md Size Default control spacing.
lg Size More spacing between controls in Chromium.
sharp Shape Square frame and Chromium control enclosure.
smooth Shape Default medium corner.
rounded Shape Pill-shaped frame.

Native attributes

Attribute Use Description
controls Required Makes the native player visible and operable.
preload="metadata" Recommended Lets the browser fetch duration without asking it to download the whole recording.
loop Optional Starts again after the recording ends.
muted Optional Starts silent while leaving the volume control available.
controlslist="nodownload" Hint Asks supporting browsers to omit their download action. It is not access control.
disableremoteplayback Optional Disables remote playback where the browser supports it.
autoplay Avoid Audible playback must start with the user.

Browser boundary

Surface Contract Fallback
Width, frame, radius, background, shadow Cross-browser None needed.
Panel, time and overflow menu colours Chromium enhancement The browser's native player.
Icons, play state, timeline, volume, control order and behaviour Browser-owned Always native; PureUI never replaces them.

Same element, source and native behaviour. The first is entirely browser-owned; the second adds the PureUI frame and, in Chromium, the private paint-only control layer.

sm, md (default) and lg change the spacing between controls in Chromium. Native control dimensions and touch targets stay under browser control.

sharp, smooth (default) and rounded set both the element frame and the Chromium control enclosure. Other engines keep their native internal corner.

Component variables are the public surface. These examples stay inside existing design tokens; unsupported engines simply use the variables that affect the outer box and retain native controls inside it.

Every preset has max-inline-size: 100%. Set --audio-inline-size: 100% when the player should fill its parent instead of stopping at a preset width. Try the 375px stage control above.

Spoken audio needs text, not only a player. A visible caption identifies the recording and a transcript lets people consume the same information without hearing it or without following it in real time.
