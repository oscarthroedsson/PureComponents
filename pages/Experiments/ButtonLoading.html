Same motion, flat grey, label hidden with color: transparent rather than visibility — so the text still sizes the box and the skeleton is exactly as wide as the real button will be. Compare each pair: identical width, no layout shift when the real one arrives.

Native disabled triggers the library's own :disabled rule, which paints the button grey — burying the brand colour the loading state is meant to keep. Either scope that rule to :disabled:not([aria-busy="true"]) in button.css, or use aria-disabled="true", which keeps the colour and the focus but does not block activation.

disabled is a real HTML boolean — its mere presence means true, and disabled="false" still means disabled. aria-* attributes are not booleans: they are enumerated strings, so they need the literal ="true".
