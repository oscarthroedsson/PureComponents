Same class on all three. No sm/md/lg, no height, no padding values in the markup — only font-size. Padding, gap, icon size and radius all derive from it.

Both rows have identical padding. The top row is trimmed with text-box: trim-both cap alphabetic, the bottom is not. Raising line-height from 1.2 to 2 changes the untrimmed button's height but leaves the trimmed one alone — that is the difference between padding measured from the letters and padding measured from the font's metric box.

text-box-trim applies to block containers only. Give the button display: inline-flex and the label becomes an anonymous flex item with nothing to trim — the declaration is still there, still valid, and silently does nothing. Both rows below declare the trim; only the first one is inline-block. Watch what raising the line-height does to the second.

em scales with the font-size number. cap scales with the height of an actual capital letter. At the same font-size, Georgia's letters are smaller than the page font's — the em button keeps its padding and looks puffy, the cap button tracks the letterforms.

Strictly proportional padding makes a large button look bloated. Mixing a fixed part with a text-relative one — calc(0.2rem + 0.45cap) — makes padding grow more slowly than the type. Top row is proportional, bottom row is damped.

Since the button is inline-block rather than flex, icons are laid out inline: sized 1cap and aligned on the baseline, so they span exactly the band the capital letters do. No icon size classes, and a button with an icon comes out the same height as one without. An icon-only button has no text to size it, so it matches its inline padding to its block padding and takes aspect-ratio: 1.

Text-driven sizing has no lower bound, and WCAG 2.2 §2.5.8 asks for a 24×24 CSS px target. A min-block-size is a floor rather than a fixed height: it does nothing until the text gets small enough that the button would be untappable.

The current .pu-btn sets padding in fixed rem values, so raising the font-size grows the text but not the box. The intrinsic button keeps its proportions at any size.
