This file declares no --btn-* variables, so the Variables row is empty — the component reads --color-primary and friends straight from main.css. The only Part is the key itself — a button has no named children. No Layout or Animations either; it is one box that does not move.

Buttons come in three sizes: small (sm), medium (md), and large (lg). Medium is the default size.

Buttons support different visual styles: primary (default), secondary, and tertiary.

Buttons can contain icons alongside text. Icons should have aria-hidden="true" to hide them from screen readers.

Icon-only buttons MUST have an aria-label attribute for screen reader accessibility.

Toggle buttons use aria-pressed to indicate their state. Use aria-pressed="true" for pressed state and aria-pressed="false" for unpressed state.

Disabled buttons use the native disabled attribute (not [disabled]). Disabled buttons are not interactive and have reduced opacity.

Buttons support different border radius styles: sharp (no radius), smooth (small radius), and rounded (large radius).

Buttons are commonly used in forms for submit and cancel actions.

Multiple buttons can be grouped together for related actions.

All buttons must be keyboard accessible and properly labeled for screen readers.
