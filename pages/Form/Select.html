Select dropdowns support three sizes: small (sm), medium (md), and large (lg).

Select dropdowns support different border radius styles: sharp, smooth, and rounded.

Select elements can allow multiple selections using the multiple attribute.

Error states require aria-invalid="true" and aria-describedby pointing to the error message.

Select elements can be disabled using the native disabled attribute.

Select elements must have proper labels and ARIA attributes for screen reader support.
