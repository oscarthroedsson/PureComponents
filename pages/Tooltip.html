The tooltip is a separate element nested inside the trigger. The trigger references it using aria-describedby and interestfor.

Set the preferred placement on the tooltip. If there is not enough available space, CSS Anchor Positioning automatically tries fallback positions.

Tooltip size controls the tooltip text size and geometry independently from the trigger.

Tooltips are available to keyboard users. Tab to the trigger to display the tooltip.

Tooltip content has a maximum width and wraps when necessary instead of overflowing the viewport.

This tooltip prefers the right side. Because the trigger is positioned close to the right edge, the browser can automatically use a fallback placement when there is not enough room.

Tooltip styling is independent from the trigger. The trigger does not need a tooltip-specific class.

Accessibility is part of the default tooltip pattern rather than a separate tooltip variant. The trigger references the tooltip using aria-describedby, while the tooltip itself uses role="tooltip".
