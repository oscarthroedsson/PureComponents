# Pill Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/pill.css`

## Implementation Details

- Button-based component
- Filter brightness for hover/active
- Transform scale on active
- Variant styles
- Size system

## Design Tokens Used

- Colors: `--color-neutral-300`
- Spacing: `--spacing-50`, `--spacing-100`
- Typography: `11px`, `12px`, `13px` (hard-coded)
- Border radius: `--radius-sm`, `--radius-md`, `--radius-full`, `0px`

## Accessibility Implementation

- Native button element
- Keyboard support
- Focus indicators (should be added)
- Hover/active states
