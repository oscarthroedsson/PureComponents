# Pagination Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/pagination.css`

## Implementation Details

- Flexbox layout for horizontal alignment
- List-based structure for semantic HTML
- Current page highlighting
- Disabled state handling
- Ellipsis for page ranges

## Design Tokens Used

- Spacing: `--spacing-15`, `--spacing-25`, `--spacing-50`, `--spacing-75`, `--spacing-100`
- Typography: `--font-size-sm`, `--font-size-md`, `--font-size-lg`
- Colors: `--color-primary`, `--color-neutral-*`
- Border radius: `--radius-sm`, `--radius-md`, `--radius-none`

## Accessibility Implementation

- Semantic nav and list structure
- ARIA current page pattern
- ARIA labels for navigation buttons
- Focus indicators
- Disabled state with proper ARIA
