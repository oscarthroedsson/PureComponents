# Table Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/table.css`

## Implementation Details

- Semantic HTML table structure
- Border collapse for clean borders
- Striped rows for better readability
- Responsive mobile stacking
- Sortable column support with ARIA

## Design Tokens Used

- Colors: `--color-neutral-*`
- Spacing: `--spacing-50`, `--spacing-75`, `--spacing-100`, `--spacing-125`
- Typography: `--font-size-sm`, `--font-size-md`, `--font-size-lg`, `--font-size-xl`
- Border radius: `--radius-sm` (for responsive mobile cards)

## Accessibility Implementation

- Semantic table structure
- Proper header scoping
- ARIA sort attributes
- Responsive accessibility (data-label attributes)
- Screen reader support
