# Search Input Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/Form/inputs/search.css`

## Implementation Details

- Search input styling with `-webkit-appearance: none`
- Search form wrapper with flexbox
- Search wrapper with icon button positioning
- Visually hidden label utility
- Clear button styling (webkit)

## Design Tokens Used

- Colors: `--color-primary`, `--color-error`, `--color-neutral-*`
- Spacing: `--spacing-25`, `--spacing-50`, `--spacing-75`, `--spacing-100`
- Typography: `--font-size-sm`, `--font-size-md`, `--font-size-lg`
- Border radius: `--radius-none`, `--radius-md`, `--radius-rounded`

## Accessibility Implementation

- Role search pattern
- ARIA labels
- Visually hidden labels
- Focus indicators
- Screen reader support
