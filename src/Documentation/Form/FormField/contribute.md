# Form Field Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/Form/inputs/formField.css`

## Implementation Details

- Flexbox column layout
- Label and input grouping
- Error/help text visibility logic
- Icon support in labels
- Size variant system

## Design Tokens Used

- Spacing: `--spacing-25`, `--spacing-50`
- Typography: `--font-size-sm`, `--font-size-md`
- Colors: `--color-neutral-900`, `--color-neutral-500`, `--color-error`
- Icon size: `16px` (hard-coded)

## Accessibility Implementation

- Label grouping
- Error message handling
- Help text association
- Disabled state styling
- Screen reader support
