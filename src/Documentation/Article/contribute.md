# Article Component - Contribution Guide

## Code Structure

- **CSS File**: `src/Styles/article.css`

## Implementation Details

- Data attribute-based styling
- Semantic HTML structure
- Typography hierarchy
- Image handling in header
- Author metadata layout

## Design Tokens Used

- Spacing: `3rem` (hard-coded), `1rem`, `0.3rem`, `4rem`, `30vh` (hard-coded)
- Typography: `1rem`, `14px` (hard-coded), `0.875rem` (hard-coded)
- Max-width: `50rem` (hard-coded)
- Border radius: `10px` (hard-coded)
- Colors: `red` (hard-coded for headings)

## Accessibility Implementation

- Semantic article structure
- Proper heading hierarchy
- Role main for content
- Time element for dates
- Footer element for author metadata
