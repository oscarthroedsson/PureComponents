The class goes on <details>, and the first child must be <summary>. That pair is the component. The browser reports the open state, takes focus, and answers Enter and Space on its own — none of it is ours to build, and none of it needs JavaScript.

One panel is a disclosure. Several that read as one block is an Accordion, which groups these and adds nothing they already do.

Attributes

Attribute Goes on Description
open the <details> Native. The panel starts open. The browser writes and removes it for you after that.
name="group" the <details> Native. Panels sharing a name form one exclusive set — opening one closes the rest. No JavaScript, no class.

data-marker="none" the <details> No marker of ours at all.

About the animation

The open and close travel is a real height transition, built on ::details-content — available everywhere since September 2025 — and interpolate-size, which is Chromium only. In Firefox and Safari the panel snaps open instead. Everything else is identical, so the animation is an enhancement and never a requirement. The marker's rotation animates everywhere; it is an ordinary transform.

interpolate-size is declared on the component rather than on :root, so one experimental property does not sit in the global scope for a single component's sake.

The class on <details>, the title in <summary>, the rest is the panel. Click it, or tab to it and press Enter.

The native open attribute. Put it on the one panel that should already be showing; the browser takes it from there.

sm, md, lg. md is what the key class alone gives you — the class is there to say it out loud. The marker is sized in em, so it follows.

sharp, smooth, rounded — the same three words as everywhere else in the library.

By default the marker closes the row: it reads as "there is more below". Move it to the front with data-marker="start" when the panel is really a branch in a tree, or drop it entirely with data-marker="none".

For an icon we do not ship, put it in the <summary> as .collapsible-marker. Ours stands down on its own — nothing to switch off — and yours picks up the size, the placement, the rotation and the timing without you writing any of it. Mark it aria-hidden="true": it is decoration, and the state is already announced.

A plus has fourfold symmetry: turn it and nothing appears to happen. So rather than animate something inside an icon, give the slot two icons and let them cross over. Add .pu-swap to the slot and mark the icons .closed and .open. The stack and the crossing come from Animations/swap.css; collapsible.css imports it, so there is nothing extra to link.

This works for any pair of shapes, because nothing inside either icon has to be animatable. The aria-hidden goes on the wrapper; both icons are decoration.

data-motion on the slot picks how the pair crosses over. Everything is expressed as an exit state — where the outgoing icon goes and where the incoming one comes from — so the four values only reassign two variables between them.

You cannot select our marker — it is a pseudo-element. So the icon is a variable instead. --collapsible-marker-icon takes a url() used as a mask, which is why the colour keeps coming from --collapsible-marker-color and not from the file.

The HTML spec allows one heading element inside <summary>, and screen reader users move through a long page by heading. On a page built out of these it is worth the markup. The heading keeps its rank and gives up its scale.

Every colour is a variable, so a panel can be restyled without a new class. This one is set inline; in a real project it would sit in your own stylesheet.

The native name attribute joins panels into one set: opening one closes the rest. It works on loose panels like these, and it is the whole mechanism behind Accordion. No script, no class.

The important instruction here is a negative one: do not add aria-expanded to the <summary>. The browser already reports open and closed from the open attribute, and an explicit aria-expanded overrides that report. We ship no JavaScript, so it could never be updated — it would announce "collapsed" while the panel stands open. The same goes for role="button": <summary> has its own role. Tab to the panel below and press Enter; that keyboard contract is everything the ARIA APG asks of a disclosure, and it arrived for free.
