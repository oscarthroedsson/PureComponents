Every key the component answers to. The fill is a gradient that stops at --range-value. CSS cannot read the input's value, so the page keeps that variable in step — one line, shown under Behavior. Without it the fill stays at 50% while the thumb still moves, works and submits.

KeyTypeDescription
.pu-rangeKeyThe key. Requires <input type="range">.
range-smSize12px type scale. Track, fill and thumb follow.
range-mdSizeThe default. The base already gives this.
range-lgSize16px type scale.
:hoverStateThe track border and the thumb darken.
aria-invalid="true"StateBorder and thumb turn to the error colour. :user-invalid does the same.
disabledStateTrack, fill and thumb go muted.
--range-valueVariablesHow far the fill reaches, as a percentage. Set it from your script.
--range-fillVariablesThe filled part. Primary by default.
--range-track-sizeVariablesOverall height, 1.15em. Fill and thumb derive from it.
--range-track-colorVariablesThe track. Reads --form-surface.
--range-border-colorVariablesThe track border. Reads --form-border-color.
--range-thumb-colorVariablesThe thumb.
--range-thumb-sizeVariablesThumb size, three quarters of the track.

No Shape: a range is always a capsule, the way a radio is always a circle, so --form-radius is not read. Always set min and max; without them the announced value is wrong.

The key and a label. Every demo on this page keeps its fill in step through the page script under Behavior.

Size moves the type scale. The track, the fill and the thumb are measured from it, so they move together.

A range with no size class takes its size from the form. It ignores the form's shape.

Invalid is reached through aria-invalid, because a range always has a value and :user-invalid rarely fires. Hover darkens the thumb, except when the range is invalid or disabled.

The fill follows the thumb because this page runs one line for every .pu-range: input.style.setProperty("--range-value", percent + "%"). The library cannot ship it. Without it the second slider below keeps its fill at the starting value while the thumb moves.

Everything below is outside the fixed section vocabulary.

Never make a slider the only way to enter a value that has to be exact. If the number means something — kronor, minutes, a percentage — say so with aria-valuetext; CSS cannot.
