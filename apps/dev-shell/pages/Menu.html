Popup menus use native popover="auto", giving light dismiss, Escape handling and top-layer rendering without JavaScript.

Menus support small, medium and large typography. Spacing scales with the menu font size.

Inline submenus use native <details> and expand inside the menu.

Inline submenus can be indented or aligned with the parent menu.

Flyout submenus use nested native popovers and CSS Anchor Positioning.

Flyout menus can contain additional flyout levels while the parent popovers remain open.

Flyouts prefer the right side. If there is not enough room, CSS Anchor Positioning automatically tries alternative placements.

Each submenu can independently choose between inline expansion and flyout behavior.

Add the horizontal class to change the menu flow.
