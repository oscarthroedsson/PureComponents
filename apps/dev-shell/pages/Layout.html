API

KeyTypeDescription
data-direction="horizontal" Layout Places direct children in a row. This is the default when direction is omitted.
data-direction="vertical" Layout Places direct children in a column.
data-layout="<top|center|bottom>-<start|center|between|around|end|split>" Layout Horizontal: vertical alignment first, horizontal distribution second.
data-layout="<start|center|end>-<top|center|between|around|bottom|split>" Layout Vertical: horizontal alignment first, vertical distribution second.

Omitting data-direction creates a horizontal row. Layout works directly on semantic elements; add pu-box only when the same element also needs Box padding or radius.

Other

Read direction first, then read the two words in data-layout against that direction.

horizontal makes inline the main axis: children flow from start to end in a row. It is also the default when the attribute is omitted.

vertical makes block the main axis: children flow from top to bottom in a column.

In a horizontal row, the first word controls the vertical cross axis. Compare top, center and bottom; the second word stays start.

In a horizontal row, the second word distributes children along the horizontal main axis. The first word stays center in every comparison.

In a vertical column, the first word controls the horizontal cross axis. Compare start, center and end; the second word stays top.

In a vertical column, the second word distributes children along the vertical main axis. The first word stays center in every comparison.

split requires exactly three direct children. In a horizontal Layout they occupy start, true geometric centre and end—even when the outer children have different widths.

The same three regions rotate with vertical. The second child remains geometrically centred from top to bottom.

Gap controls only the space between direct children. Box padding remains independent around the group.

Use --layout-gap only when none of the six shared gap values fits the composition.

Complete interface parts built only from existing PureUI components.

center-split gives the horizontal navbar three regions. The search stays geometrically centred even when the groups on either side differ in width.
