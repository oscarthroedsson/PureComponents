Markup the library cannot supply

Attribute Goes on Description
aria-label="Breadcrumb" the <nav> Tells this landmark from the page's other navs.
role="list" the <ol> list-style: none makes WebKit stop announcing it as a list at all. This writes the role back without bringing the numbers with it.
aria-current="page" the current crumb On the element, never on the <li>. Carries the meaning; the colour only follows it.
aria-hidden="true" your own separator Decoration. Ours is kept away from assistive tech already.

The class goes on the <ol>. The <nav> and its label belong to the page, and so does role="list" — see Accessibility below.

sm, md, lg. md is what the key class alone gives you — the class is there to say it out loud.

The default mark is >. Four variant classes reassign it and do nothing else: slash, chevron, arrow, dot.

For a mark we do not ship, set --breadcrumbs-separator yourself. On the <ol> it changes every gap; on a single <li> it changes only the gap after that crumb, because custom properties inherit.

When the mark has to be an icon or an SVG, put it in the <li> as .breadcrumbs-separator. Our own mark stands down on its own — nothing to switch off — and the last crumb hides its separator either way, so a loop can emit the same markup for every item.

sharp, smooth, rounded. Corners only show once something is drawn behind them, so these demos set --breadcrumbs-crumb-background. The crumbs already carry the padding.

The same three words work one level down. A crumb that carries its own shape wins; one that does not falls back to the list's. The list below is sharp — only the middle crumb is rounded.

aria-current="page" goes on the element, never on the <li>. It is what the styling hangs on — leave it off and the crumb renders as a plain link, which is the honest result: without it the page has not been marked as current for anyone.

The row wraps rather than overflowing. Narrow the width control above to see it.

Three things belong to the markup, not to us: <nav aria-label="Breadcrumb"> so the landmark can be told from the page's other navs; role="list" on the <ol>, because list-style: none makes WebKit stop announcing it as a list at all; and aria-current="page" on the current crumb. The separator is decoration and is kept away from assistive tech.
