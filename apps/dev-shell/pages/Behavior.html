API

KeyTypeDescription
data-behavior="auto|expand|compact" Layout Applies one explicit behavior to both inline and block.
data-behavior="inline-<auto|expand|compact>" Layout Changes inline only. Block keeps the component's base sizing.
data-behavior="block-<auto|expand|compact>" Layout Changes block only. Inline keeps the component's base sizing.
data-behavior="<inline>-<block>" Layout Sets both axes independently; each word is auto, expand or compact.
auto Layout Explicit CSS automatic sizing. It is not the same as omitting an axis.
expand Layout Fills the available space on the selected axis.
compact Layout Uses content-sized space on the selected axis.

The search changes inline only and takes the slack. Block is omitted, so every control keeps its component height. Behavior only needs a direct parent with data-layout; neither element has to be a Box.

No attribute keeps both component bases. A named axis changes only that axis. Two behavior words always read inline first and block second.

Input is full-width by base. Omitting inline preserves that; inline-auto deliberately replaces it with automatic inline sizing.

inline-expand fills the row but keeps Button's base height. The single word expand fills both the remaining inline space and the height established by the reference Box.

Two behavior words always mean inline first and block second.

The outer row gets its height from the reference Box. The vertical workspace expands to that height, then its middle control takes the remaining block space and the available inline space.

Complete interface parts built only from existing PureUI components.

Nested Boxes let the action group stay inline-compact while the query field owns the flexible inline region. Neither overrides block, so every control retains its component height.

Each List expands inline and keeps its own block sizing. Long content can shrink inside an equal column instead of forcing the Box wider.
