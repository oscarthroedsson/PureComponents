Use role="status" for non-urgent updates and role="alert" for important, time-sensitive messages.

Decorative intent icons should use aria-hidden="true". Their size follows the alert typography.

Alerts support soft styling by default, plus outline and filled variants.

Alert geometry scales from its typography using relative CSS units.

Alert actions reuse the existing Button component instead of defining alert-specific button styling.

Dismiss controls reuse the Button component. Removing the alert from the DOM requires the application's behavior layer.

Titles and icons are optional. Simple status messages can contain only alert content.
