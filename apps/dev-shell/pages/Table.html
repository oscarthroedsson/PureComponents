The class goes on the <table>. Every cell is reached from there.

table-start (default), table-center and table-end. The class works at any level, because text-align inherits — the nearest ancestor that sets a value wins, and a value set directly on an element always beats an inherited one.

The baseline is table-start rather than the browser default, which gives td start and th center — a header centred over left-aligned data.

table-sm, table-md (default) and table-lg move cell padding and type size together.
