Media, header, body and footer. Every part is optional and independent — the card sets no width of its own, so the parent decides how wide it gets.

A card with nothing but a body has to look finished. Nothing else is required.

DOM order decides. Move .card-header above .card-media and it renders there — no extra class, no variant. The media always runs edge to edge, and the part next to it keeps its full padding.

sm, md (default) and lg change density — padding and type scale — not width. Width belongs to the parent. Cap it with --card-max-width if you need to.

No rules between the parts. The seam between two parts measures exactly one --card-padding-block — the same as the gap to the card's own edge — so the rhythm is even all the way down without a single border.

horizontal puts the media beside the content; column is the default and needs no class. Which side the media lands on comes from DOM order — media first is leading, media last is trailing. Set the column width with --card-media-inline-size.

Unequal text, level footers. The card fills the height its grid cell gives it, the body takes the slack, and the footer is pushed to the bottom. Nothing about the markup differs between these three.

Default is a surface with a border. outline drops the fill, ghost drops both, and elevated adds a shadow.

sharp, smooth (default) and rounded. The media is clipped to the same radius, so an image never breaks the corner.

Images arrive in whatever shape they arrive in. Set --card-media-aspect-ratio and every one crops to the same box, so a row of cards keeps its top edges honest.

data-interactive turns the whole card into the hit area for the one link marked .card-link. The link is the only tab stop, and the focus ring is drawn on the card because the link's real box is an invisible overlay. Tab into it to see. Any other control inside — the second card's button — stays clickable in its own right.

The component variables are the public surface. Set them inline and the card changes without a stylesheet being touched.
