API

KeyTypeDescription
.pu-overflow Key Allows automatic scrolling on both axes.
.overflow-x Layout Allows horizontal scrolling and closes the vertical axis.
.overflow-y Layout Allows vertical scrolling and closes the horizontal axis.
--overflow-x Variables Controls horizontal overflow; defaults to auto.
--overflow-y Variables Controls vertical overflow; defaults to auto.

The key enables both axes. The fixed preview size only establishes the boundary that makes overflow observable.

A named axis is the only one users can scroll. Descendants keep ownership of their own sizing and wrapping behavior.

The component variables accept the native CSS overflow values.
