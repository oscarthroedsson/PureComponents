Every key the component answers to. Wrap the list in a <nav> with an aria-label, and put role="list" on the list — the component removes the bullets, and WebKit drops the list role from a list styled that way. For nested links use Menu.

KeyTypeDescription
.pu-navKeyThe key. Requires <ul> or <ol>, inside a named <nav>.
nav-itemLayoutOne item. Goes on each <li>.
nav-linkLayoutThe link inside an item. Carries the fill, the corner and every state.
nav-horizontalLayoutA row. The default.
nav-verticalLayoutA column. Links stretch to the list's width.
nav-smSizeSmaller type and tighter links.
nav-mdSizeThe default. The base already gives this.
nav-lgSizeLarger type and roomier links.
nav-sharpShapeSquare link corners.
nav-smoothShapeThe default corner.
nav-roundedShapePill-shaped links.
aria-current="page"StateThe current page. Filled, bolder, and does not answer to hover.
aria-disabled="true"StateDimmed and not clickable.
:hoverStateA sunken ground and the primary colour.
--nav-gapVariablesSpace between links.
--nav-link-padding-blockVariablesLink padding, top and bottom.
--nav-link-padding-inlineVariablesLink padding, start and end.
--nav-link-radiusVariablesLink corner.
--nav-link-hover-backgroundVariablesHover ground.
--nav-current-backgroundVariablesCurrent page fill.
--nav-current-colorVariablesCurrent page text.

The key, a size and the current page.

Size moves type, padding and the gap between links. Medium is the default.

Direction and shape. Shape reaches the link, because the link is the thing with a fill.

aria-current="page" marks where you are and ignores hover. A disabled link uses aria-disabled, because an <a> can never be :disabled. Hover the other links.
