API

KeyTypeDescription
.pu-separator Key The key on a native <hr>. Horizontal by default.
separator-vertical Layout A vertical rule that takes the block size its parent already provides.
--separator-thickness Variables The line thickness. Defaults to 1px.
--separator-color Variables The line colour. Defaults to var(--color-border).

The key alone is horizontal. Native <hr> supplies the separator semantics; the component removes the browser's margins and lets the parent's gap own the surrounding space.

The vertical modifier stretches to the height the row already gets from its content. Keep aria-orientation="vertical" beside the class so semantics and presentation agree.

Both rules fill only space the parent already has. Their zero minimum sizes and shrinkable Flex participation let the parent constrain them instead of being enlarged by them.

Thickness and colour are variables rather than named variants, so the same API accepts any suitable length and design token.

Semantics

Use the native separator when the break between regions is meaningful. Add aria-hidden="true" when a line is only decoration, and never make it the only cue that two regions differ.

Complete interface parts built only from existing PureUI components.

A vertical separator groups related actions without setting the toolbar's height. The buttons establish the row; the separator only occupies that available block size.

Horizontal separators divide complete settings rows. The parent owns all spacing through data-gap; the separators add no hidden margins of their own.
